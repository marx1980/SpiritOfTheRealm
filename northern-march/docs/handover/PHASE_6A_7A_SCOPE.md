# Northern March Interaction Prototype

## Objective
Close one complete causal loop: Anna needs grain -> delegates acquisition -> grain moves -> communities experience consequences -> beliefs/grievances form -> leaders react -> cooperation changes -> imperfect reports return to Anna.

## Phase 6A communities
Northwatch, Greyfen, Eastmere and Blackwood Settlements only. Each has 2-3 cohorts, material condition, sparse beliefs, memory, grievance, source trust, organisations and behaviour state.

## Behaviour ladder
Cooperate, petition, delay, conceal/withhold, refuse later demand, support a named actor. No full armed rebellion yet.

## Phase 7A grain
Only grain: stores, production, consumption, requisition, convoy movement, loss/seizure and scarcity bands. Exact stock conservation required.

## Grain Crisis
Northwatch needs grain. Greyfen can provide some at real cost and remembers a Crown consultation promise. Anna has imperfect estimates. Varos can exploit grievance only with access and organisation.

## Required outcomes
Cooperative support; material success/political damage; political caution/military danger; misinformation failure. Outcomes must emerge from state, not scripted branches.

## Genericity check
Run a second grievance stimulus such as troop misconduct, broken protection promise or appointment dispute before accepting the architecture.
