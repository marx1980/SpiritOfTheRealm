# Northern March Interaction Prototype

## Package contents
This package consolidates the current design, architecture, implementation, testing, playtesting, metrics, and handover material.

## Current direction
The early prototype tests imperfect knowledge, autonomous NPCs, delegated intent, population politics, material consequences, and later battlefield command. Queen Anna is the only playable ruler. Succession is deferred.
