# Northern March Interaction Prototype

## World pipeline
World event -> observers -> observations -> sparse belief updates -> reports/rumours -> transmission -> recipient beliefs -> relevant agents wake -> candidate actions evaluated through beliefs/objectives/traits/relationships/skills -> plan/action -> execution -> new events -> memories/reputation/grievances/resources.

## NPC pipeline
Trigger -> update beliefs -> check current intention -> continue or replan relevant layer -> generate few candidates -> evaluate -> select -> store DecisionTrace -> execute/communicate.

## Player command pipeline
Speech/typed input -> technical normalisation -> conversational intent draft -> adviser questions/recommendations/read-back -> natural affirmation -> StructuredOrder -> physical transmission -> interpretation -> obedience/adaptation -> local plan -> execution.

## Population pipeline
Material/political event -> community experience/report -> belief -> memory/grievance -> competing narratives -> support/cooperation change -> organisation/leadership -> collective behaviour.

## Performance pipeline
Update affected state only; identify observers; update relevant beliefs; wake implicated agents only; choose planning depth by tier; schedule resulting actions; return agents to dormant/current-plan state.
